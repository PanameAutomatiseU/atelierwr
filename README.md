# Galerie Nus, Atelier WR

41 fichiers originaux récupérés depuis Wix, après comparaison de 15 captures de la galerie /nus, de juin 2021 à juillet 2026.

25 images figurent dans la dernière capture (12 juillet 2026). Les 16 autres proviennent de versions antérieures. Les fichiers distincts peuvent inclure plusieurs versions d’une même œuvre.

- `originaux/` : fichiers conservés sans redimensionnement ni recompression.
- `web/` : JPEG de 1400 pixels maximum, qualité 82.
- `planche-contact.jpg` : aperçu des 41 fichiers.
- `inventaire.json` et `inventaire.csv` : titres Wix disponibles, URLs originales et dimensions. Le JSON conserve aussi les empreintes SHA-256 et dates des captures.

Les titres génériques ou absents ont été conservés sans inventer de titre d’œuvre. La galerie Wix contenait également quelques portraits ou scènes de plage : les fichiers ont été récupérés selon leur présence dans cette galerie, sans modifier leur classement.

Source : https://www.atelierwr.net/nus

Archive récente : https://web.archive.org/web/20260712121532/https://www.atelierwr.net/nus

Site Wix confirmé : db6a6acd-9c99-4fc3-a8f3-95481c980263.

La collecte couvre les images identifiées dans les archives disponibles, pas les médias privés de Wix ni les éventuels ajouts postérieurs à juillet 2026. Cette sauvegarde ne modifie pas le site publié.
